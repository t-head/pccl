# PCCL Agent Guide

Use the existing project guidance relevant to the task:

- [CONTRIBUTING.md](CONTRIBUTING.md): contribution workflow, coding conventions, commit messages, DCO, and pull requests.
- [Issue templates](.github/ISSUE_TEMPLATE/): when preparing an issue, choose the Bug, Feature, Question, or Task template and follow its prompts.
- [.agents/review_rules.yaml](.agents/review_rules.yaml): shared code-review checklist.
- [pccl-contribution](.agents/skills/pccl-contribution/SKILL.md): read and follow this skill when creating issues, preparing commits or PRs, handling review feedback, or publishing or merging changes.
- [README.md](README.md): build and validation instructions.

Keep detailed policies in their source documents. Report only builds and tests actually performed, and state validation limitations explicitly.
